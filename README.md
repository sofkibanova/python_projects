Предсказание следующего товар

Цель — построить простую рекомендательную систему, которая предсказывает следующий товар, с которым взаимодействует пользователь, на основе истории его просмотров. Предварительных знаний по машинному обучению не требуется — мы проверяем навыки Python, понимание теории вероятностей и умение рассуждать о данных и результатах.

1. Распределение длин сессий
2. Топ-20 самых частых товаров
3.  Частота товара по рангу

Анализ графиков:

1. Справа один из столбцов заметно выше многих в середине. Есть высокие столбцы слева относительно тех, что по середине, сама середина по высоте низкая. То есть два участка повыше, чем в середине - слева и справа. 

2.  Столбцы очень разной высоты. Даже среди самых частых есть 3-4 штуки, которые сильно выше остальных, поэтому видно самых популярных.

3. График начинается высоко слева и потом понемногу идет вниз, то есть нет обрывов. И еще в конце идет практически прямая линия. Предполагаю, что много товаров с меньшей частотой, тут видно полную выборку.


Почему случайное различения для таких данных не подходит?
Для каждой сессии: в train — все товары кроме последнего, в test — только последний.
1. Порядок важен. Нужно предсказать «что после уже показанной истории». Если клики из одной сессии перемешать между train и test, в обучение могут попасть события, которые в этой цепочке были позже целевого — модель подсматривает будущее, метрика завышена.
2. Утечка (leakage). Случайное разбиение по просмотрам рвёт сессию: контекст в train и test перестаёт соответствовать тому, что в проде доступно «до следующего шага».
3. Другая задача. Случайный split измеряет не «угадай следующий после префикса», а смесь ситуаций; для next-item это неверная постановка оценки.
